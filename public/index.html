School Locations
NYC Department of Education via NYC Open Data. Point locations for all NYC public elementary schools with DBN identifiers, grades served, principal, address, and neighborhood (NTA). Loaded as static GeoJSON; 1,030 schools.
School Zone Boundaries
NYC DOE 2024-2025 Elementary School Zones. Polygon boundaries joined to schools by DBN/system_code.
Test Scores
NYC DOE InfoHub NYS Grades 3-8 ELA & Math assessment results. Excel files downloaded and processed via Python (openpyxl) into per-school JSON keyed by DBN, year, subject, and grade. Proficiency = % scoring Level 3 + Level 4. Currently using seed data; replace with real InfoHub download via scripts/download-scores.sh and scripts/process-scores.py.
Subway Lines & Stations
NYC Open Data via ArcGIS REST API (lines, stations). Fetched client-side with pagination (resultOffset). MTA route colors mapped from line designations.
Housing Listings
Realty in US API via RapidAPI (apidojo). For-sale and recently-sold listings queried by the zip codes configured in the HOUSING_ZIP_CODES environment variable. Filtered server-side to 3+ bed, 1,500+ sqft; sold homes limited to last 12 months. Cached daily in data/housing-cache.json. Deduplicated by property ID.
Driving Isochrones
OpenRouteService /v2/isochrones/driving-car. Time-based isochrone polygons at 10/20/30/45-min intervals. Congestion scaling factor applied client-side (0.5x-1.0x speed).
Transit Isochrones
Geoapify Isoline API /v1/isoline. Public transport isochrones incorporating subway, bus, and walking. Requires GEOAPIFY_API_KEY.
Geocoding
OpenStreetMap Nominatim. Client-side address lookup bounded to NYC metro area. Used for isochrone origin input.
Base Map
CARTO Voyager vector tiles rendered via MapLibre GL JS. Open-source, no API key required.
